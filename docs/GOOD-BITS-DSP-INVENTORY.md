# The Good Bits: DSP inventory (moved)

The inventory of The Good Bits' DSP (what each algorithm does, whether it streams, and how it is
reused) moved with the code to Slop Factory Core: `docs/GOOD-BITS-DSP.md` in
<https://github.com/clickysteve/slopfactory-core>. The vendored Good Bits files, their
`vendor.json` (upstream commit and SHA-256 of every file) and the provenance test are there too.

ANVIL keeps Good Bits' generic processing names and describes no processor as an emulation of a
particular machine.
