# MIDI foundation (moved)

The MIDI audit of the instruments, the shared MIDI interfaces and the migration roadmap moved to
Slop Factory Core: `docs/MIDI-ROADMAP.md` in <https://github.com/clickysteve/slopfactory-core>.
Core contains MIDI **interfaces only**; ANVIL's MIDI code (`src/midi/`, `src/transport/`) is
its own and unchanged.
